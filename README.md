# 3D Minecraft - 网页版我的世界

一个使用 Three.js 构建的 3D Minecraft 克隆游戏，完全运行在浏览器中。

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)
![Three.js](https://img.shields.io/badge/Three.js-000000?style=flat&logo=three.js&logoColor=white)

## 游戏特色

- **无限世界生成** - 程序化生成的地形，包括平原、山脉、森林
- **方块系统** - 多种方块类型：泥土、石头、矿石、树木、水等
- **生存模式** - 饥饿值、生命值、工具耐久度系统
- **创造模式** - 无限资源、飞行模式、无敌状态
- **合成系统** - 使用合成台制作工具和物品
- **熔炼系统** - 使用熔炉冶炼矿石和烹饪食物
- **战斗系统** - 多种敌对生物：僵尸、骷髅、苦力怕、蜘蛛
- **生物系统** - 被动生物：猪、牛、鸡
- **天气系统** - 动态天气变化，包括下雨效果
- **昼夜循环** - 真实的白天/黑夜循环
- **盔甲系统** - 皮革、铁、钻石盔甲提供不同防御力
- **经验值系统** - 击杀生物和挖掘方块获得经验

## 操作说明

### 基本移动
| 按键 | 功能 |
|------|------|
| W/A/S/D | 前后左右移动 |
| 空格 | 跳跃 |
| Shift | 冲刺 |
| 鼠标移动 | 视角控制 |

### 游戏操作
| 按键 | 功能 |
|------|------|
| 鼠标左键 | 破坏方块/攻击 |
| 鼠标右键 | 放置方块/使用物品/进食 |
| 滚轮 | 切换快捷栏物品 |
| 数字键 1-9 | 选择快捷栏物品 |

### 功能按键
| 按键 | 功能 |
|------|------|
| E | 打开物品栏 |
| C | 打开合成台 |
| F | 打开熔炉 |
| F5 | 切换视角（第一/第二/第三人称） |
| F6 | 切换游戏模式（生存/创造） |
| ESC | 暂停游戏 |

### 创造模式专属
| 按键 | 功能 |
|------|------|
| 空格（双击） | 切换飞行模式 |
| 空格（飞行中） | 上升 |
| Shift（飞行中） | 下降 |

## 游戏机制

### 生存模式
- **饥饿值** - 移动和冲刺会消耗饥饿值，饥饿值过低会持续掉血
- **生命值** - 受到攻击或饥饿会减少生命值，饥饿值充足时缓慢恢复
- **工具耐久** - 使用工具会消耗耐久度，耐久度归零后工具损坏
- **经验值** - 挖掘方块和击杀生物获得经验值

### 合成系统
在工作台（按 C 打开）中可以合成：
- 木板、木棍
- 石砖、玻璃
- 各种工具（镐、剑、斧）
- 盔甲（皮革、铁、钻石）
- 其他物品

### 熔炼系统
在熔炉（按 F 打开）中可以冶炼：
- 铁矿 → 铁块
- 金矿 → 金块
- 圆石 → 石砖
- 沙子 → 玻璃
- 生肉 → 熟肉

### 敌对生物
| 生物 | 特点 |
|------|------|
| 僵尸 | 近战攻击，夜间生成 |
| 骷髅 | 远程射箭，夜间生成 |
| 苦力怕 | 接近后爆炸，夜间生成 |
| 蜘蛛 | 快速移动，夜间主动攻击 |

### 被动生物
| 生物 | 掉落物 |
|------|--------|
| 猪 | 生猪排 |
| 牛 | 生牛排、皮革 |
| 鸡 | 生鸡肉、羽毛 |

## 安装与运行

### 方法一：直接打开
直接在浏览器中打开 `index.html` 文件即可游玩。

### 方法二：本地服务器（推荐）
使用 HTTP 服务器运行以获得最佳体验：

```bash
# 使用 Python
python -m http.server 8080

# 使用 Node.js (需要先安装 http-server)
npx http-server -p 8080

# 使用 PHP
php -S localhost:8080
```

然后在浏览器中访问 `http://localhost:8080`

## 技术栈

- **Three.js** - 3D 渲染引擎
- **HTML5 Canvas** - 游戏画面
- **CSS3** - UI 界面样式
- **JavaScript** - 游戏逻辑
- **Pointer Lock API** - 鼠标锁定
- **Web Audio API** - 音效（计划中）
